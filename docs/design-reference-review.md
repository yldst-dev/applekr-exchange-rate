# 디자인 참고 기록

2026-09-10에 ego-browser로 아래 사이트에 직접 접근해 페이지 구성과 공개 설명을 확인했습니다. 외부 컴포넌트나 서체는 설치하지 않았습니다.

## 적용 방향

편집형 가격표를 기준으로 제품 선택과 계산 결과를 하나의 비교 영역에 배치합니다. HeroUI 기본 서체, 색상, 조작 요소를 유지합니다. 금액은 큰 글씨로, 세금과 출처는 읽을 수 있는 보조 글씨로 구분합니다. 주요 구분은 여백과 얇은 선으로 표현합니다.

| 참고 사이트 | 확인한 내용과 적용 판단 |
| --- | --- |
| [Beautiful UI](https://www.beautifului.dev/) | 검색과 여러 표 예시를 제공하는 구성입니다. 가격 비교는 표 구조를 유지합니다. |
| [beUI](https://beui.dev/) | 동작 중심의 컴포넌트 예시를 확인했습니다. 계산 결과에는 추가 등장 효과를 넣지 않습니다. |
| [Rare UI](https://www.rareui.com/) | 개성이 강한 동작 예시를 확인했습니다. 이 계산기의 반복 작업에는 적용하지 않습니다. |
| [Transitions.dev](https://transitions.dev/) | 목적별 전환 예시를 확인했습니다. 기존 모달과 목록의 이동 동작을 유지합니다. |
| [shadcn/ui](https://ui.shadcn.com/) | 접근성을 갖춘 조합형 조작 요소를 확인했습니다. 같은 역할을 맡은 HeroUI를 유지합니다. |
| [UI Skills](https://www.ui-skills.com/) | 숫자 폭 정렬, 제목 줄바꿈, 44px 터치 영역 기준을 적용했습니다. |
| [Coss UI](https://coss.com/ui) | 큰 제목과 작은 설명의 위계, 얇은 구분선을 참고했습니다. |
| [Design System Checklist](https://www.designsystemchecklist.com/) | 디자인 언어, 기초, 컴포넌트, 유지보수의 구분을 확인했습니다. 기존 디자인 체계 안에서 수정합니다. |
| [ReUI](https://reui.io/components) | 검색 가능한 컴포넌트 목록과 Data Grid 항목을 확인했습니다. 비교 기능은 별도 모달로 유지합니다. |
| [You Don’t Need Animations](https://emilkowal.ski/ui/you-dont-need-animations) | 동작의 목적과 사용 빈도를 함께 고려하는 원칙을 확인했습니다. 요청된 자동 이동과 조작 반응만 유지합니다. |
| [Swag UI](https://swagui.rohoswagger.com) | 일관된 글자 크기 체계와 정보 밀도 설정을 확인했습니다. 새 테마 대신 기존 색상과 서체를 유지합니다. |

## 반영 내용

- 계산 패널 2개를 하나의 표면과 내부 구분선으로 묶었습니다.
- 헤더 높이와 상단 여백을 줄이고 제목 위계를 강화했습니다.
- 작은 보조 글씨를 12px 이상으로 조정했습니다.
- 가격과 환율 열은 오른쪽으로 맞추고 숫자 폭을 일정하게 했습니다.
- 테마 전환, 순위 이동, 페이지 이동의 터치 영역을 44px 이상으로 늘렸습니다.
- 세금 기준은 배지 대신 보조 글씨로 표시합니다.
- 순위 목록의 제품 이미지와 금액 위치를 맞췄습니다.
- 모달의 상단 정보와 하단 페이지 이동 고정을 유지합니다.

## 점검 기준

자동 검사에서 감지된 출처 링크의 밑줄과 테마 아이콘은 실제 기능이 있어 유지합니다. 새 그라데이션, 장식용 카드, 그림자, 추가 폰트는 도입하지 않습니다. 모바일 가로 넘침, 모달 스크롤, 어두운 화면을 브라우저에서 확인합니다.


## Apple 제품 전시형 리뉴얼

Apple 한국 스토어를 ego-browser로 직접 열어 제품 이미지, 제목 위계, 제품 목록과 탐색 요소를 확인한 뒤 전면 리뉴얼했습니다.

- 방향은 차분한 제품 전시형입니다. HeroUI의 기본 서체, 중립색과 파란 강조색을 유지합니다.
- 페이지 제목은 64px, 주요 섹션은 28px에서 36px, 일반 설명은 12px에서 15px로 역할을 구분합니다.
- 큰 표면은 24px, 입력창과 작은 정보 영역은 12px 모서리를 사용합니다.
- 제품 이미지를 선택창 앞에 놓고, 모델명과 실제 비교 금액을 강조합니다.
- 순위 목록의 독립된 제품 표면은 Apple 스토어의 탐색 방식을 참고한 의도적인 구성입니다. 내부 카드와 그림자는 추가하지 않습니다.
- 헤더 블러, 출처 링크 밑줄과 기능 아이콘은 기존 요청과 접근성을 위해 유지합니다.
- 모달, 메인 화면, 어두운 화면, 모바일에서 동일한 글자와 간격 규칙을 사용합니다.
- `.catalog-pagination`처럼 프로젝트 전용 이름을 사용해 HeroUI 컴포넌트의 스타일과 충돌하지 않게 합니다.
