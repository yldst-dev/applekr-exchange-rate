# Apple 환율 계산기

Vite, React, HeroUI v3 기본 디자인 체계, TypeScript로 만든 한국·미국 Apple 공식 가격 비교 사이트입니다. Cloudflare Workers에서 화면과 조회 데이터를 제공하고 GitHub Actions에서 하루 1회 가격과 환율을 수집합니다. 로컬 개발과 자체 호스팅에는 기존 Node.js 서버를 사용할 수 있습니다.

## Cloudflare Workers 배포

`main` 브랜치에 푸시하면 검증과 빌드 후 자동 배포합니다. 한국 시각 09:00에 일일 수집과 배포를 예약하며 실제 실행 시각은 GitHub 작업 상태에 따라 늦어질 수 있습니다. 이전 배포에서 마지막 확인값을 복구하므로 일부 수집 실패에도 기존 가격을 유지합니다.

필요한 GitHub 설정과 운영 절차는 [Cloudflare 배포 안내](docs/cloudflare.md)를 참고하세요.

## 실행

Node.js 22.12.0 이상이 필요합니다. Docker에서는 Node.js 24를 사용합니다.

```sh
npm ci
npm run dev
```

개발 화면은 `http://localhost:5173`, 서버는 `http://localhost:3001`입니다. 최초 실행 시 공식 데이터를 수집하므로 결과 표시까지 시간이 걸릴 수 있습니다. 빈 상태를 표시한 뒤 30초마다 갱신 상태를 확인합니다. 임의의 예제 가격을 실제 가격처럼 표시하지 않습니다.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

프로덕션 서버의 기본 주소는 `http://localhost:3000`입니다.

## Dokploy 배포

1. `yldst-dev/applekr-exchange-rate` 저장소의 `main` 브랜치를 연결한 Docker Compose 서비스를 만듭니다.
2. Compose 경로를 `compose.yaml`로 지정합니다.
3. Dokploy의 Domains에서 도메인을 추가하고 서비스 `app`, 컨테이너 포트 `3000`을 지정합니다.
4. HTTPS를 활성화하고 배포합니다. Dokploy가 도메인 라우팅에 필요한 네트워크와 설정을 추가합니다.
5. `/api/health` 응답의 `ready`가 `true`가 되면 가격과 환율을 모두 확보한 상태입니다.

[Dokploy 공식 도메인 연결 안내](https://docs.dokploy.com/docs/core/docker-compose/domains)를 따릅니다. `compose.yaml`은 호스트 포트를 열지 않습니다. Docker Stack이 아닌 Docker Compose 배포를 사용합니다.

로컬 Docker 실행에는 추가 파일을 적용합니다.

```sh
docker compose -f compose.yaml -f compose.local.yaml up --build -d
```

`http://localhost:8080`에서 확인합니다. 컨테이너는 일반 사용자, 읽기 전용 루트 파일 시스템, 권한 추가 제한으로 실행됩니다. 가격 데이터만 `catalog-data` 볼륨에 저장됩니다. 아키텍처를 강제하지 않아 호스트에 맞는 `amd64` 또는 `arm64` 이미지를 빌드합니다.

상세 배포와 백업 절차는 [Dokploy 운영 안내](docs/deployment.md)를 참고하세요.

## 환경 설정

| 변수            | 기본값   | 설명                                                       |
| --------------- | -------- | ---------------------------------------------------------- |
| `SYNC_HOUR_KST` | `9`      | 한국 시각 기준 자동 수집 시각으로 0부터 23까지 설정합니다. |
| `PORT`          | `3000`   | 서버 포트입니다. Compose에서는 3000을 사용합니다.          |
| `DATA_DIR`      | `./data` | 데이터 저장 폴더입니다. 컨테이너에서는 `/app/data`입니다.  |
| `APP_PORT`      | `8080`   | 로컬 Compose 파일에서만 사용하는 호스트 포트입니다.        |

API 키는 필요하지 않습니다. Compose 설정은 셸 환경 또는 `.env`에서 읽습니다. Node.js 직접 실행 시에는 셸 환경 변수를 전달합니다.

## 자동 갱신과 저장

최초 시작 시 데이터를 수집하고, 이후 한국 시각 기준 하루 1회 수집합니다. 최초 수집과 같은 한국 날짜에는 예약 시각이 와도 다시 수집하지 않습니다. 수집 시도 시각을 볼륨에 기록하므로 재시작으로 같은 날 수집을 반복하지 않습니다. 중단된 수집은 다음 수집일에 다시 시도합니다.

Apple 한국·미국 스토어의 제품 링크를 따라가며 모델별 가격을 읽습니다. Apple 제작 액세서리는 마지막 페이지까지 읽습니다. 동시에 가져오는 제품 페이지는 최대 3개입니다. 요청은 25초 후 중단하며 응답은 12MB로 제한합니다. 외부 스크립트를 실행하지 않고 JSON만 해석합니다.

환율은 [Frankfurter v2](https://frankfurter.dev/)에서 `providers=ECB`로 지정한 유럽중앙은행의 최신 USD/KRW 일일 공시값입니다. 휴일에는 최근 영업일 값이 유지됩니다. 공시 날짜와 조회 시각을 구분해 표시합니다.

파일 저장은 임시 파일을 쓴 뒤 교체합니다. 일부 가격 수집에 실패하면 해당 출처의 이전 가격과 확인 시각을 유지합니다. 환율 조회 실패 시 이전 공시값을 유지합니다. 실패 내역은 화면에서 펼쳐 확인할 수 있습니다. 이전 가격은 36시간 경과 시 오래된 가격으로 표시합니다. 이전 값도 없으면 비교 불가 상태를 표시합니다.

개발 중 수집기를 직접 실행할 수 있습니다. 동일 데이터 폴더에 쓰는 서버를 먼저 중지합니다.

```sh
npm run sync
```

볼륨을 지우면 마지막 확인값과 수집 이력이 사라집니다. `docker compose down`은 볼륨을 유지합니다. `data/catalog.json` 파일을 백업하면 됩니다. 파일 기반 저장을 사용하므로 동일 볼륨에 쓰는 서버는 1개만 실행합니다.

## 가격 비교 범위

지원 제품군은 iPhone, Mac, iPad, Watch, AirPods, Vision, TV 및 홈, 디스플레이, Apple 제작 액세서리입니다. 판매 모델명과 가격을 코드에 고정하지 않습니다. 양국의 모델 식별값과 확인 가능한 옵션이 일치하는 경우만 계산합니다.

- iPhone은 미국 통신사 약정 옵션을 제외한 언락 일시불 가격을 사용합니다.
- iPad 등은 용량, 색상, 연결 방식, 화면 등 구매 페이지에 제공된 옵션을 비교합니다.
- Mac은 칩, 메모리, 저장 장치, 디스플레이 식별값이 일치하는 표준 구성을 비교합니다. 지역별 키보드, 전원 어댑터 및 기본 제공품은 다를 수 있습니다. 주문 제작 추가 옵션 가격은 포함하지 않습니다.
- Watch는 케이스, 크기, 통신 방식별 기본 밴드 포함 시작 가격입니다. 모든 밴드 조합의 총액을 계산하지 않습니다.
- 액세서리는 기본 제품 번호가 같은 항목을 연결합니다. 지역별 제품 번호가 다른 항목은 이름이 비슷해도 자동으로 연결하지 않습니다.
- 상세 옵션이 제공되지 않고 구조화된 시작 가격만 확인되면 시작 가격임을 표시합니다.
- 교육 할인, 리퍼비시, 보상 판매, 통신사 할인, 구독 서비스, 서드파티 제품은 비교 범위에 포함하지 않습니다.

Apple 페이지 구조나 판매 상태에 따라 수집 가능한 구성이 바뀝니다. 전체 제품군을 탐색하지만 모든 국가에서 모든 제품이 판매되거나 모든 옵션의 가격이 공개되는 것은 아닙니다. 가격이 없거나 같은 구성을 확인하지 못하면 추측하지 않습니다. 구매 주소가 같은 국가와 제품군의 소개 페이지 또는 구매 목록으로 이동하면 판매 목록에서 제외합니다. 접속 실패, 다른 국가로의 이동, 가격 분석 실패는 계속 수집 오류로 표시합니다.

## 계산

```text
세전 Apple 추정 환율 = 한국 가격 / 1.1 / 미국 가격
표시 가격 기준 환율 = 한국 가격 / 미국 가격
환율 차이율 = (Apple 추정 환율 / 기준 환율 - 1) * 100
세전 모드의 원화 환산 가격 = 미국 가격 * 기준 환율 * 1.1
```

계산 중에는 반올림하지 않고 화면 표시 단계에서만 반올림합니다. 제품 식별값과 부가세 표시 모드를 URL에 담아 결과를 공유할 수 있습니다. 이 값은 Apple 내부 가격 결정 환율을 의미하지 않습니다.

## 구조

| 경로                    | 역할                                                                        |
| ----------------------- | --------------------------------------------------------------------------- |
| `src/domain`            | 제품·가격·환율 자료형과 순수 계산 함수입니다.                               |
| `src/application`       | 저장소·데이터 출처 계약과 동기화 정책입니다.                                |
| `server/infrastructure` | Apple 수집, Frankfurter 연동, 파일 저장, 외부 요청 제한입니다.              |
| `server/index.ts`       | HTTP 서버, 정적 파일 제공, 일일 갱신 실행입니다.                            |
| `src/infrastructure`    | 브라우저의 서버 조회 구현입니다.                                            |
| `src/presentation`      | HeroUI 화면과 조회 상태를 관리합니다.                                       |
| `tests`                 | 세금·환율 계산, 제품 매칭, 오류 보존, 갱신 일정, 외부 주소 제한 검증입니다. |

클라이언트는 외부 페이지를 직접 수집하지 않습니다. 읽기 전용 `/api/catalog`와 `/api/health`만 제공하며, 방문자 요청으로 수집을 시작하거나 임의 주소를 서버가 가져오게 할 수 없습니다.
